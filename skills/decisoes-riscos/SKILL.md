# Decisões e riscos

Escolha o modo pelo pedido. Não carregar ambos por rotina nem abrir outro agente.

- **Testar a tese:** ler [crítica](references/critica.md) para confrontar uma recomendação, estratégia ou crença consequente.
- **Antecipar falhas:** ler [premortem](references/premortem.md) antes de uma mudança cara ou difícil de reverter.

Uma passada proporcional basta. Se ambos forem necessários, reutilizar premissas e evidências; não repetir a mesma crítica. Sustentar objeções, distinguir fato de hipótese e não inventar riscos para preencher uma lista. Incorporar o ajuste prático na resposta; mostrar a análise completa somente quando pedida ou necessária para decidir. Analisar não autoriza executar a decisão.
